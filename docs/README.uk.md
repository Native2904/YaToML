# YaToML

Плагін Lister (WLX) для Total Commander для перегляду та редагування
файлів **YAML** і **TOML** у вигляді дерева та таблиці замість
звичайного тексту.

YAML і TOML постійно трапляються в сучасній розробці: Docker Compose,
маніфести Kubernetes, workflow-файли GitHub Actions/GitLab CI, плейбуки
Ansible та Helm-чарти (YAML), а також `Cargo.toml` у кожному проєкті на
Rust і `pyproject.toml` для сучасного пакування Python та таких
інструментів, як `ruff` чи `black` (TOML).

## Можливості

- **Перегляд у вигляді дерева й таблиці**: дерево зліва (структура),
  таблиця справа (Key / Type / Value) показує дочірні елементи
  вибраного вузла — клік по рядку Map/List переходить усередину,
  подвійний клік по рядку зі значенням відкриває редагування.
- **Редагування на місці**: подвійний клік або клавіша F2 на
  скалярному значенні (String, Integer, Float, Bool, дата/час) відкриває
  поле введення прямо в таблиці. Enter підтверджує, Escape скасовує.
- **Збереження (Ctrl+S)**: зміни записуються на диск методом *патча* —
  замінюються лише байти фактично змінених значень. Коментарі та
  форматування в іншій частині файлу залишаються недоторканими.
  - **TOML**: повністю підтримується для всіх скалярних типів, включно
    з датою/часом.
  - **YAML**: підтримується для однорядкових звичайних і взятих у
    лапки скалярів (основний випадок). Багаторядкові блокові значення
    (`|`, `>`) та значення всередині flow-структур (`{...}`/`[...]`)
    розпізнаються та безпечно відхиляються з попередженням, а не
    вгадуються — файл при цьому ніколи не пошкоджується, просто ці
    конкретні значення поки не зберігаються.
  - Обов'язкова перевірка заново розбирає результат після кожного
    збереження і перериває запис (нічого не зберігаючи), якщо щось не
    відповідає очікуванням.
- **Контекстне меню** (правий клік або Shift+F10/клавіша меню): у
  дереві — розгорнути/згорнути все, у таблиці — редагувати
  значення/скопіювати значення/скопіювати ключ, перехід від рядка
  таблиці до відповідного вузла дерева, а також збереження.
- **Рядок стану**: показує шлях (breadcrumb) вибраного вузла та
  індикатор незбережених змін.
- **Темна тема**: опційно, за замовчуванням вимкнена. Вмикається через
  `yatoml.ini` (див. нижче) — незалежно від власної кольорової схеми
  Total Commander.

## Встановлення

1. Скопіювати `yatoml.wlx64` (64-біт) та/або `yatoml.wlx` (32-біт) у
   папку на власний вибір.
2. У Total Commander: Конфігурація → Налаштування → Плагіни →
   Lister-плагіни → Налаштувати → Додати, і вказати файл
   `.wlx64`/`.wlx`. Призначити розширенням `yaml`, `yml`, `toml` (або
   довіритися автоматичному визначенню Total Commander).
3. Опційно: розмістити `yatoml.ini` у тій самій папці, що й DLL
   плагіна, щоб увімкнути темну тему (див. нижче).

## Темна тема

Не пов'язана з кольоровою схемою самого Total Commander. Створити або
відредагувати `yatoml.ini` поруч із DLL плагіна:

```ini
[Settings]
DarkMode=1
```

`DarkMode=0` (або відсутність файлу) зберігає звичайний світлий вигляд.
Налаштування зчитується заново під час кожного відкриття файлу —
перезапуск не потрібен, достатньо закрити й знову відкрити вікно
Lister (або відкрити наступний файл).

## Відомі обмеження

- YAML: багаторядкові блокові значення та значення у flow-стилі можна
  переглядати, але поки не можна зберігати (див. вище) — при цьому
  показується зрозуміле попередження, файл не пошкоджується.
- Поки немає відображення у вигляді звичайного тексту (планується як
  друга вкладка поруч із таблицею).
- Якорі/аліаси YAML під час завантаження розв'язуються прозоро
  (показується їхнє підсумкове значення); сам зв'язок аліаса не
  відображається і не редагується.
