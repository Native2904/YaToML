# YaToML

Плагин Lister (WLX) для Total Commander для просмотра и редактирования
файлов **YAML** и **TOML** в виде дерева и таблицы вместо обычного
текста.

YAML и TOML постоянно встречаются в современной разработке: Docker
Compose, манифесты Kubernetes, workflow-файлы GitHub Actions/GitLab CI,
плейбуки Ansible и Helm-чарты (YAML), а также `Cargo.toml` в каждом
проекте на Rust и `pyproject.toml` для современной упаковки Python и
таких инструментов, как `ruff` или `black` (TOML).

## Возможности

- **Просмотр в виде дерева и таблицы**: дерево слева (структура),
  таблица справа (Key / Type / Value) показывает дочерние элементы
  выбранного узла — клик по строке Map/List переходит внутрь,
  двойной клик по строке со значением открывает редактирование.
- **Редактирование на месте**: двойной клик или клавиша F2 на
  скалярном значении (String, Integer, Float, Bool, дата/время)
  открывает поле ввода прямо в таблице. Enter подтверждает, Escape
  отменяет.
- **Сохранение (Ctrl+S)**: изменения записываются на диск методом
  *патча* — заменяются только байты фактически изменённых значений.
  Комментарии и форматирование в остальной части файла остаются
  нетронутыми.
  - **TOML**: полностью поддерживается для всех скалярных типов,
    включая дату/время.
  - **YAML**: поддерживается для однострочных обычных и заключённых в
    кавычки скаляров (основной случай). Многострочные блочные значения
    (`|`, `>`) и значения внутри flow-структур (`{...}`/`[...]`)
    распознаются и безопасно отклоняются с предупреждением, а не
    угадываются — файл при этом никогда не повреждается, просто эти
    конкретные значения пока не сохраняются.
  - Обязательная проверка заново разбирает результат после каждого
    сохранения и прерывает запись (ничего не сохраняя), если
    что-то не соответствует ожиданиям.
- **Контекстное меню** (правый клик или Shift+F10/клавиша меню): в
  дереве — развернуть/свернуть всё, в таблице — редактировать
  значение/скопировать значение/скопировать ключ, переход от строки
  таблицы к соответствующему узлу дерева, а также сохранение.
- **Строка состояния**: показывает путь (breadcrumb) выбранного узла и
  индикатор несохранённых изменений.
- **Тёмная тема**: опционально, по умолчанию выключена. Включается
  через `yatoml.ini` (см. ниже) — независимо от собственной цветовой
  схемы Total Commander.

## Установка

1. Скопировать `yatoml.wlx64` (64-бит) и/или `yatoml.wlx` (32-бит) в
   папку по своему выбору.
2. В Total Commander: Конфигурация → Настройки → Плагины →
   Lister-плагины → Настроить → Добавить, и указать файл
   `.wlx64`/`.wlx`. Назначить расширениям `yaml`, `yml`, `toml` (или
   довериться автоматическому определению Total Commander).
3. Опционально: поместить `yatoml.ini` в ту же папку, что и DLL
   плагина, чтобы включить тёмную тему (см. ниже).

## Тёмная тема

Не связана с цветовой схемой самого Total Commander. Создать или
отредактировать `yatoml.ini` рядом с DLL плагина:

```ini
[Settings]
DarkMode=1
```

`DarkMode=0` (или отсутствие файла) сохраняет обычный светлый вид.
Настройка считывается заново при каждом открытии файла — перезапуск не
требуется, достаточно закрыть и снова открыть окно Lister (или открыть
следующий файл).

## Известные ограничения

- YAML: многострочные блочные значения и значения в flow-стиле можно
  просматривать, но пока нельзя сохранять (см. выше) — при этом
  показывается понятное предупреждение, файл не повреждается.
- Пока нет отображения в виде обычного текста (планируется как вторая
  вкладка рядом с таблицей).
- Якоря/алиасы YAML при загрузке разрешаются прозрачно (показывается
  их итоговое значение); сама связь алиаса не отображается и не
  редактируется.
